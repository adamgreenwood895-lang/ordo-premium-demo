# Ordo Premium Demo

A mobile-first premium shopping demo with voice-style landing, category browsing, product cards, tracking, and payment screens.

## Setup
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.

## Deploy to GitHub Pages
Use Vite's GitHub Pages deployment guide and keep `base: '/ordo-premium-demo/'` in `vite.config.js` [web:15].
